## The shared brain — 3 tiers + the wall

**Principle: never depend on an agent remembering bookkeeping. Derive state mechanically;
agents contribute only work products.**

- **T1 LIVE (SQLite):** task board (agent, task, status, owned files, started_at — written by
  dispatch lifecycle events, NOT by agents) + shared chat transcript.
- **T2 TRUTH (files):** work products in known lanes — gemini→docs/research/\*.md,
  claude→docs/specs/, codex→code+commits. `docs/project-state.md` is REGENERATED by zer0
  every turn from board+git+index; agents read it, never write it. Derived state cannot rot.
- **T3 RECALL (SQLite FTS5 + sqlite-vec):** findings/lessons ledger; post-turn sweep indexes
  new work products; dispatch preamble injects semantic-recall hits.
- **Compliance is observed, not assumed:** research dispatch with no .md landed → yellow flag
  on the agent card. State stays correct either way (derived).
- **THE WALL:** review-mode dispatches read a FILTERED context (diff + spec, never the
  writer's reasoning artifacts) — enforced at the prefilter seam (headless-prompt.ts).
  Coordination plane shares work products; verification plane isolates. This is the moat:
  chat for coordination, isolation for review, and the system knows which plane it is in.

## Gate Topology — cross-family is a REVIEW topology, not an assignment topology

(Operator correction 2026-06-09; supreme over lane defaults — TEAM.md §1.7 is the canonical text.)

Cross-family value fires at three checkpoints: **plan review → brief review → post-build code
inspection** — never at "which model builds." Observed failure being corrected: a builder
executing another model's brief degrades into a dumb executor (loses its own coding agency).
Therefore: the BUILDER AUTHORS ITS OWN BRIEF from an objective + acceptance criteria; the other
family attacks the plan and the brief BEFORE build and the diff AFTER; claude or codex may build
any given task (lanes are capability defaults/tiebreaks). The one invariant exception: gemini
never builds (md-only = blast-radius safety). The capstone's gemini-PRD → claude-design →
codex-build script is ONE valid configuration of this topology, not the topology itself.

## The Team Pack — per-agent native preload (operator's idea, adopted)

One source (`TEAM.md`, the team constitution) compiles into each agent's NATIVE config surface
via `zer0 team sync`. Packs are COMPILED, NEVER HAND-EDITED (pattern proven by
"GEMINI.md — generated from ROUND_TABLE.md").

| Agent  | Surfaces                                                      | Content                                                 |
| ------ | ------------------------------------------------------------- | ------------------------------------------------------- |
| claude | project CLAUDE.md + `.claude/skills/zer0-teammate`            | architecture/synthesis lane, file map, handoff format   |
| codex  | AGENTS.md + config.toml profile (gpt-5.5, effort low) + skill | builder lane, owned-files discipline, escalation rights |
| gemini | GEMINI.md                                                     | md-only boundary, citation mandate, research lanes      |

Every pack carries 5 things in the agent's dialect: (1) role + lane, (2) file map — where truth
lives, where YOUR output goes, (3) wake-up protocol — read project-state.md + board first,
(4) handoff-proposal format, (5) that agent's empirically-banned behaviors (gemini fabricated
findings; codex scope-creep; claude over-specified briefs).

**Why native surfaces, not per-turn prompt stuffing:** position (system-adjacent at session
start = strongest instruction-following), persistence (read once per persistent session,
cached every turn — stuffing re-pays tokens per message on codex's tight budget), machinery
(rides each vendor's own instruction-privileging path: claude skill loader, codex AGENTS.md,
gemini context files).

## Why each layer choice (one line each)

- Ink: framework vindicated; flicker was one-shared-transcript layout. Master-detail isolates
  the high-frequency render region.
- Deterministic conductor: routing/locks/approvals must never depend on an LLM.
- Mixed transports: billing dictates them (claude pty-only verified; codex app-server same
  OAuth); ACP-shaped seam keeps them swappable.
- Files+SQLite: all three vendor CLIs converged on files-as-truth + index-on-top.
- Temporal (right binary): durable mid-activity crash resume that a state file cannot give.
